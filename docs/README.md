# UART RTL-to-GDS Project

## Project Overview
This repository documents my journey in digital design, Verilog RTL development, functional verification, and ASIC design flow.

## Learning Objectives
- Learn digital electronics fundamentals.
- Develop RTL modules using Verilog HDL.
- Simulate and debug designs using Icarus Verilog.
- Analyze waveforms using GTKWave.
- Learn synthesis and the RTL-to-GDSII flow.

## Tools
- Verilog HDL
- Icarus Verilog
- GTKWave
- Git and GitHub

## Project Status
Stage 1: Environment setup and digital design fundamentals.
